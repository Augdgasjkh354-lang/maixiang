# 麦乡 · 小镇岁时

一座以粮食为本的古代小镇模拟经营游戏。你是新任镇长：种麦、盖作坊、定工资和税率、推行粮券货币改革、卖厂给民营或整栋上市、开外贸、调贫富，看一项政策如何牵动全镇的就业、物价与民生。

当前版本：**0.2.3**（最新改动见 [`CHANGELOG.md`](CHANGELOG.md)，存档结构 v17，旧存档都能读）

## 怎么玩

用浏览器直接打开 `index.html` 即可，单文件、无需联网、无需安装。进度自动保存在本机浏览器，可导出导入存档。

开局只有麦田：先在南林伐木点盖伐木场（不需要木材），有了木材再盖磨坊、面包房、批发市场和商业街。建筑建成后要给岗位派人，否则没有产出。

## 主要系统

- **农业与口粮**：农事日累计决定秋收，农业税在镇库与居民间分粮。
- **产业链**：小麦 → 磨坊 → 面粉 → 面包房 → 面包；伐木、盐场、棉田 → 织坊、酒坊；mod 加了茶叶、陶器、丝绸（桑园）。镇营加工按市场需求生产，积压就减产，不会吃空口粮储备。
- **流通与物价**：批发市场做市（可开自动调价），综合商店按库存调价——积压降价、紧缺涨价。养殖基地出肉，时代广场摆摊。
- **所有制**：一栋产业建筑整栋只有一个主人（镇里、一户人家或一家公司）。可整栋卖给民营、整栋上市；民营和公司自己决定升级，欠薪太久由镇里收回。
- **货币与金融**：建银行后一键改用粮券；存款付真实利息、存款也算家底；交易所、国债、社保基金。
- **外贸**：多座外镇；运力由外贸房、物流中心、码头（河岸地）提供；贸易中心里的私人贸易行自己做进出口。
- **民生与再分配**：家底与宽裕度决定居民买什么；救济、失业金、养老金、雇主缴社保；富人税（分档累进）、遗产税、整户无人家产归公（店铺由他人接手不清算）；戏园、别墅等富人消费；人口面板看基尼系数和贫富曲线。

所有税率默认关闭，由你在政策页自己开。

## 开发

```bash
node --test                                        # 测试
node scripts/bundle-single.mjs --out index.html    # 从 src/ 重新打包 index.html
node scripts/simulate.mjs scenarios/<场景>.json    # 数值模拟
node scripts/health-check.mjs 10                   # 十年经济体检（可加 --wealth-tax 1,3,5 等政策参数）
```

接手开发先读 [`AGENTS.md`](AGENTS.md)。加新内容优先写成 mod，见 [`MODDING.md`](MODDING.md)。架构见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)，各子系统设计见 `docs/`（所有制 `OWNERSHIP.md`、外贸 `TRADE.md`、再分配 `REDISTRIBUTION.md` 等）。
