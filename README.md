# 《麦乡》0.1.10 · 存档性能与年度摘要

0.1.10 保留既有存档性能、统一支付、家庭与公司系统。r08 新增镇营批发市场并把产业原料采购统一接入批发库存；面粉、面包、盐的居民零售收口到综合商店，综合商店按批发价固定加价20%；商业街新增学堂与饭店，并加入30天店员最低在岗期。存档结构仍为 v15。

## 本版变化

- **存档容器 v2**：同一状态只生成一次用于持久化的 JSON 文本；校验和直接复用这份文本。读取 v2 容器时不再把已解析 state 重新 stringify 后再 parse。旧容器 v1 继续兼容并保留完整校验。
- **自动保存单飞**：同一时刻只有一个保存任务。保存期间的新修订合并为后续一次最新保存；旧修订完成不会清除新 dirty。切档、新建和删除前等待在途保存，并用运行期 session/修订号隔离旧任务。
- **年度摘要**：存档结构升级到 **v15**。年报只保存人口/劳动力、年度收支与税收、家庭生活、公司/店铺年度账与利润分配摘要；不再逐年复制公司/店铺日级历史、当前日账和完整历年分红史。
- **旧档迁移**：v14 年报按已有数据转换为摘要；公司已完成的年度分配优先从现有分配历史精确保留。旧店铺年报若无法安全推导历史分配额则保留未知，不猜值。完整运行态中的分配结算标记继续保留，读取后不会重复分配。

核心玩法仍为：镇营产业等级 → 成立独立公司 → 独立经营 → 建成交易所并完成货币改革后上市。
