# 麦乡 · 小镇岁时

一座以粮食为本的古代小镇模拟经营游戏。你是新任镇长：种麦、盖作坊、定工资和税率、推行粮券货币改革、扶持公司上市，看一项政策如何牵动全镇的就业、物价与民生。

当前版本：**0.2.3「流通改革」**（存档结构 v15）

## 怎么玩

用浏览器直接打开 `index.html` 即可，单文件、无需联网、无需安装。进度自动保存在本机浏览器。

开局只有麦田：先在南林伐木点盖伐木场（不需要木材），有了木材再盖磨坊、面包房、批发市场和商业街。建筑建成后要在「镇民」页给岗位派人。

## 主要系统

- **农业与口粮**：农事日累计决定秋收，农业税在镇库与居民间分粮。
- **产业链**：小麦 → 磨坊 → 面粉 → 面包房 → 面包；伐木场出木材，盐场出盐。
- **流通**：批发市场挂收购价/售价做市，综合商店按目标利润率动态定价卖给居民。
- **劳动力市场**：商店按失业率调薪、高薪挖人；镇营工资由政策系数调控。
- **货币改革**：建银行后从小麦实物过渡到粮券，完成后可开交易所、让公司上市。
- **民生与财政**：舒心值、救济、邻里互助、失业金、社保基金、别墅与房产税、国债、外镇贸易。
