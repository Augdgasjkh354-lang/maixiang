# 0.1.10-r04 定向验证

本修订只覆盖工资/欠薪、商业街、换券、公司估值/分红/认购，以及 r03 民营采购和新公共岗位的直接回归。游戏版本保持 0.1.10，存档结构保持 v15；未进行全量测试或多年经济模拟。

## 实际修复范围

- 镇库工资：商业街 `managedBy="shops"` 聚合岗位不再进入 `payDailyWages`。r03 已形成的可识别聚合幽灵欠薪在载入/日结时安全清理，真实镇营家庭债权仍独立于当前岗位、退休、人数归零或建筑撤销继续偿还。
- 商业街：单店最多 4 商人 / 20 店员，继续使用 `shop:<id>:merchant/clerk` 家庭岗位；两类员工都由店铺形成工资债权。服务需求频率、容量提高，新增需求/成交/支付不起/容量不足/满足率诊断；自动扩招只把有支付能力但容量不足的需求作为扩招信号。
- 换券：取消独立兑付储备。外部账户交出的小麦直接进入镇库；自动换券、直接换券、混合支付使用同一汇率和整数精度。旧 v15 储备首次载入一次性并回镇库并保留成本基数。
- 公司估值：统一为真实净利润、投入资本和利润率口径；库存不直接增加估值。观察窗口仍按日历日计算，停工日不从估值窗口剔除；交易所和认购预览使用同一整数每股参考值，实际认购复用预览。360 日周转金只继续约束利润分配。
- 复核 r03：公司工资按 company ID 独立读写；民营磨坊购麦→面包房购粉→面包销售连续日结；银行 8 人、交易所 8 人、每座公租房 20 名管理员岗位与默认工资保持一致。
