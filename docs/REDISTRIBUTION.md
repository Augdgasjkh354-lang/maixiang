# 再分配工具箱（0.2.3-r22 起）

所有税率默认 0（关闭），由镇长在政策页自己开。

## 1. 富人税（按家底分档、累进）

- 家底（征税口径）= 粮券 + 银行存款 + 超出口粮储备的小麦（按券值）+ 股票市值（实时股价）+ 名下民营建筑估值。
- 按**人均**家底分三档，门槛默认 300 / 1000 / 3000 券，年税率默认 0% / 0% / 0%（政策可调，每档 0–20%）。
- 超额累进：只对超过某档门槛的那部分按该档税率算（同累进个税）。一户应纳 = 人口 × Σ 各档（min(人均家底, 下一档门槛) − 本档门槛）⁺ × 本档税率。
- 每 30 天收一次，税率按年率 ÷ 12。付款顺序：粮券 → 存款 → 小麦（不动口粮储备）；付不起的部分当月免征，不卖股票不卖楼。钱进镇库。
- 政策字段 `state.policy.wealthTax = { thresholds: [300, 1000, 3000], ratesPercent: [0, 0, 0] }`。

## 2. 遗产税

- 年终人口结算后，有成年人去世的家庭：遗产份额 = 该户家底 × 去世成年人数 ÷ 去世前成年人数；对超过富人税第一档门槛 ×（去世人数）的部分按遗产税率征收，默认 0%（政策可调 0–50%）。
- 整户都没了（家庭失效）：全部家产归镇库（粮券、存款、小麦、库存、股票划给镇库；名下民营建筑收归镇营，走 `transferBuildingOwnership`）。这一条不受税率影响，一直生效。
- 别墅：整户失效时名下的别墅撤销售出记录，回到空置，欠税一并免除；之后由日结的别墅销售再卖出（计入 `escheatVillas`）。
- 店铺：整户失效时名下的店铺（综合商店、贸易行、养殖场等，集体摊位除外）不关门、不清算，由新业主接手，现金、库存、负债、员工与经营设置原样保留，利润改付给新业主。候选顺序：本店商人（岗位多者优先）→ 本店店员（岗位多者优先）→ 家底最厚的一户（不含已在同类宿主建筑开店的人）；平局取粮券多者。无人可接手则店铺暂停并记一次事件（之后每日再试，不重复记）；日结店铺步骤也会为旧档里业主已失效的孤儿店做同样的交接。
- 政策字段 `state.policy.inheritanceTaxPercent`。

## 3. 雇主缴社保

- 社保缴费照旧每人每天 `dailyPerWorkerJin`，但改为**雇主替员工交**：雇主承担比例默认 100%（政策可调 0–100%），其余员工家庭自己交。
- 雇主按岗位归属认定：镇营岗位 → 镇库；民营建筑 → 业主家庭；公司 → 公司；店铺（商人/店员）→ 店铺。务农、自雇没有雇主，全额由家庭自己交。
- 雇主付不起的部分记为"社保欠缴"（`socialSecurity.employerArrears[owner]`），不算欠薪，不触发收回；之后有钱时优先补缴。
- 政策字段 `state.socialSecurity.employerSharePercent`（默认 100）。

## 4. 富人消费

- **戏园**：商业街的新服务店（`serviceId: "theater"`）。票价高、店员多；只有宽裕度 ≥ 1.5 的家庭才去，收入弹性高，舒心值比茶馆高。
- **丝绸**（mod `silk`）：新产业建筑"桑园"（原料级，`industryTier: 0`），每名桑农每天产 10 斤丝绸，等级和熟练度照常加成。丝绸批发参考价 100 券/斤，上商店货架、可批发、可出口（外镇收丝绸）。日用品需求里收入弹性 2.0：穷人几乎不买，富人买得多，用了加舒心值。

## 5. 贫富面板

- 人口面板：基尼系数、最富 1% / 10% 占全镇家底、各税档人家数、本年富人税与遗产税收入；基尼系数逐年曲线。
