# 所有制（0.2.3-r19 起）

一栋产业建筑（`industryTier` 建筑）**整栋只有一个主人**：镇里、某一户人家，或一家公司。不再按等级拆着卖。

## 数据表示

沿用 `building.ownership = { townLevels, privateLevels, listedLevels }`，但加一条不变量：**三者恰好一个等于 `building.level`，其余为 0**。

| 主人 | ownership | 其他字段 |
|---|---|---|
| 镇里 | townLevels = level | — |
| 一户人家 | privateLevels = level | `building.privateOwners = [householdId]`（长度恰好 1） |
| 公司 | listedLevels = level | `company.buildingId` 指向它，`company.listedLevels = level` |

岗位键不变：镇营 `jobKeyForBuilding`、民营 `privateJobKeyForBuilding`、公司 `listedJobKeyForBuilding`。换主人时把在岗人数从旧键整体搬到新键（不超过新主人的岗位上限）。

`validateState` 校验上面的不变量。

## 换主人的四条路

1. **卖给民营**（镇长操作）：整栋出售。要价默认 = 估值，镇长可改；买家 = 付得起的家庭中家底最多的一户（不再合资）。钱付给镇库。
2. **上市**（整栋）：建筑的主人（镇里或某户）把整栋建筑放进一家新公司并挂牌，**一步完成**，不再有单独的"成立公司"。
   - 总股本默认 10 万股；本次卖出比例由镇长定，默认 49%；每股价格由镇长定（默认按估值 ÷ 总股本）。
   - 原主人持有其余股份：镇里 → `townShares`；某户 → `householdShares[owner]`。
   - 卖出的股份进入发行池（`shareSale.offeredShares`，`shareSale.sellerOwner` 记卖方），居民认购，**股款付给原主人**。
   - 镇营建筑：镇长直接操作。民营建筑：业主每 30 天看一次，经营好且想扩张（现金不够升级）就递交上市申请（`state.ipoApplications[buildingId]`），**镇长批准才上市**，可驳回。
3. **镇里收回**（自动）：民营业主欠薪连续超过 30 天，或业主付不出工资且现金为 0 超过 30 天 → 整栋收回镇营。
   - 先用业主名下这栋楼的原料存货抵欠薪（按批发收购价折算），不够的由镇库垫付给工人；业主拿不到补偿。
   - 公司同理（欠薪超过 30 天）：清算现金和存货先还欠薪，不够镇库垫；股票作废（居民和社保基金的股份一并注销，不补偿）；建筑回镇营。
4. **镇里收购**（镇长操作，可选）：按估值向民营业主买回整栋。

## 升级

- 镇营：镇长照旧手动升级，镇库出钱。
- 民营、公司：**主人自己决定**。每 30 天检查一次：近 60 天利润 > 0，岗位已满（在岗 ≥ 上限的 90%），现金 ≥ 升级花费 + 60 天工资 → 付钱升级。
  - 升级花费 = 材料按批发价折算 + 工日 × 建筑工工资，一次性付给镇库；之后工程照常由镇里施工。
  - 升级完成，新等级归原主人（`privateLevels`/`listedLevels` +1，公司股本不变）。

## 股票

- 镇里持有的股份**不会自动卖出，也不会自动回购**。居民日常买股只能买发行池里（镇长或业主挂出来的）股份。
- 社保基金买卖股票、镇库回购居民股份仍是镇长手动操作。

## 旧存档换算

读档时按等级拆开的建筑整栋交给**等级最多的一方**（平手归镇里）：
- 其余民营业主按"每级估值"由镇库补偿（镇库付不起就按能付的付，并记事件）。
- 镇里多 → 公司/民营的等级划回镇里；公司若因此没有等级，按清算处理（股份注销，镇库按股价补偿居民持股）。
- 公司多 → 镇营等级并入公司（镇里按每级股本拿股份），民营等级先由镇库按估值买回再并入。
- 民营多 → 多户业主中等级最多的一户得整栋，其他户按每级估值由镇库补偿；镇营和公司等级同理并入（公司被清算）。
