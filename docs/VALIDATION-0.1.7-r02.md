# 0.1.7-r02 修复与验证记录

## 修复范围

- 历史镇营工资债权独立于当前岗位、工资设置和建筑状态偿还；旧债先偿、当日工资后处理，改革“缺券未付”按实际偿还递减。
- 股票认购预览、实际认购和界面业绩统一使用最近最多365个日历日的实际净利润估值，停工日计入；无历史明确显示暂无业绩。
- 公司360日周转金尊重显式 `targetWorkers=0`；未设置目标时才回退计划人数，既有债务不受影响。
- 居民年度利润分配纳入投资收入；新年先重置当日家庭账再记录分配，上一年度利润仍由年度结算快照读取。
- 镇库回购和上市公司等级划入/划回增加确认前预览；确认时重新计算，关键结果变化后必须再次确认。
